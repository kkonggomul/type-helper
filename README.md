# 이미지 → Word 변환기

Gemini로 JPG/PNG 또는 PDF 한 파일을 읽고 Word(.docx)로 저장하는 Streamlit 앱입니다.

## 실행

```sh
pip install -r requirements.txt
streamlit run app.py
```

사이드바에 Gemini API 키를 입력하고 모드와 파일을 선택한 뒤 **변환 시작**을 누릅니다.
결과를 원본과 비교한 후 **워드 파일 다운로드**를 누르세요.

## 모드

- **시험 문제 추출** (기본값): 기존 프롬프트와 Word 변환기를 유지합니다. 낙서와 부가 설명을 제외하고 문제·보기·지문·표를 추출합니다.
- **일반 내용 그대로 전사**: 제목, 설명, 학습 목표, 예시, 주석, 페이지 정보, 읽을 수 있는 필기를 포함합니다. 요약이나 번역 없이 원문 순서를 유지하며 판독 불가는 `[판독 불가]`로 표시하도록 요청합니다.

전사 모드의 Word 출력은 제목 1–6, 문단, 굵게/기울임, 들여쓴 글머리 목록, 원래 번호를 유지한 번호 목록, 표와 셀 줄바꿈을 지원합니다. 번호는 자동 재번호 매기기를 피하려고 텍스트로 보존합니다. Unicode 수식은 보존하고, LaTeX 수식은 Word에서 편집 가능한 수식 객체로 변환합니다. 분수·첨자·지수와 한글을 포함한 aligned 다중 행 수식을 지원합니다. 변환에 실패하면 수식 원문을 남깁니다. 병합 셀, 그림, 정확한 페이지 배치는 재현되지 않을 수 있습니다. 그림의 캡션과 텍스트는 전사하도록 요청합니다.

모드 또는 입력 파일을 변경하면 이전 결과를 초기화합니다. 전사 파일명은 `_원문전사.docx`, 기존 모드 파일명은 `_변환.docx`로 끝납니다.

## 검증

```sh
python -m unittest -v test_app
```

Word 구조와 기존 문제 출력, 두 모드의 이미지/PDF 요청, 모드 전환, 빈 응답 및 API 오류를 검사합니다. API 응답을 대체한 자동 테스트이며 실제 이미지 인식 정확도는 유효한 Gemini API 키와 원본 자료로 별도 확인해야 합니다.

기존 `google-generativeai` 의존성은 변경하지 않았습니다. 해당 SDK는 지원 종료 경고를 출력하므로 향후 `google-genai`로의 이전이 필요합니다.
